# Drivana Frontend

Next.js frontend for Drivana car rental platform.

## Setup

```bash
npm install
npm run dev
```

## Pages (To be implemented)

### Public Pages
- `/` - Homepage
- `/vehicles` - Browse vehicles
- `/drivers` - Browse drivers
- `/login` - Login page
- `/register` - Registration page

### Client Pages
- `/dashboard` - Client dashboard
- `/reservations` - My reservations
- `/profile` - User profile

### Driver Pages
- `/driver/dashboard` - Driver dashboard
- `/driver/missions` - Driver missions
- `/driver/earnings` - Driver earnings

### Admin Pages
- `/admin/dashboard` - Admin dashboard
- `/admin/users` - User management
- `/admin/vehicles` - Vehicle management
- `/admin/drivers` - Driver validation
- `/admin/reservations` - Reservation monitoring
